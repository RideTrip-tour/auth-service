# Управление пользователем

Этот документ описывает эндпоинты, относящиеся к текущему пользователю.

## Получение профиля

`GET /api/users/me`

Возвращает текущего авторизованного пользователя.

## Смена пароля

`POST /api/users/me/change-password`

Требует:

- `current_password`
- `new_password`

Поведение:

- текущий пароль проверяется через `verify_password`;
- новый пароль сохраняется через `UserManager.update`;
- после обновления отправляется письмо-подтверждение;
- refresh token пользователя удаляются;
- выполняется logout, чтобы старые сессии перестали работать.

## Запрос смены email

`POST /api/users/me/request-change-email`

Требует:

- `current_email`
- `new_email`
- `password`

Поведение:

- проверяется пароль пользователя;
- проверяется совпадение `current_email` с текущим email аккаунта;
- проверяется, что новый email ещё не занят;
- создаётся JWT с `type=change_email`;
- письмо уходит на текущий email;
- подтверждение выполняется через `POST /api/auth/verify`.

## Ответы

Оба новых эндпоинта возвращают объект вида:

```json
{"status": "..."}
```

## Схемы

Схемы запросов описаны в `app/schemas/users.py`:

- `UserUpdatePassword`
- `UserUpdateEmail`
